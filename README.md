# Пепельные нити

Исходный проект прототипа 0.2.0 на **Godot 4.4.1 / GDScript** для браузера.
Русский интерфейс. Основной целевой формат первой проверки — ПК.

Маленький сшитый хранитель Стежок ищет свет в заброшенной ткацкой мастерской.
Проломи проходы, подготовь маршрут, забери три ядра и вернись в убежище.
Первое ядро запускает тревогу: у тебя 140 секунд, а Сборщик начинает охоту.

## Что реализовано в исходниках

- Один 3D-уровень с подготовкой маршрута, сбором предметов, победой и поражением.
- Десять разрушаемых групп: перегородки, ящики и короткая преграда, всего 324 блока.
- Проверка опоры: блоки, не связанные с нижним рядом, обрушиваются.
- Киянка без ограничения ударов; импульсная катушка с пятью зарядами.
- Три одноразовых узла нити: каждый восстанавливает 25 здоровья и два импульса.
- Металлическая перегородка выдерживает один удар киянкой.
- До 48 временных физических обломков; они не сталкиваются друг с другом и игроком.
- Сборщик преследует игрока над мастерской; стены перекрывают его луч урона.
- Свободный режим без тревоги и урона.
- Меню, пауза, управление звуком, подсказки, сохранение текущей попытки и рекорда.
- Сенсорные кнопки и площадка движения как экспериментальная поддержка телефона.
- Собственная геометрия, сшитые руки героя, кукла-хранитель, четыре оригинальных звуковых файла.

Это **не полный аналог физического движка Teardown**: разрушаются выделенные
блочные конструкции; пол, несущий каркас, трубы и станки остаются целыми.
Сборщик — упрощённый воздушный противник, не сложная система навигации.
Вдохновение — подготовка разрушениями короткого маршрута и атмосфера маленьких
тряпичных существ в огромном мёртвом мире. Названия, персонажи, модели, музыка
и сюжет фильма «9» и игры Teardown не перенесены.

## Проверить в Godot

1. Установи обычный Godot **4.4.1**, не .NET-версию, и matching Export Templates.
2. Импортируй `project.godot`.
3. Дождись импорта ресурсов и нажми F6/F5: основная сцена `scenes/main.tscn`.
4. Сначала проверь свободный режим, затем полную попытку с тревогой.

Управление:

| Действие | Кнопки |
| --- | --- |
| Движение | WASD, вверх / вниз |
| Обзор | Мышь; Q/E или влево/вправо; T/G вверх/вниз |
| Разрушение | ЛКМ или R |
| Забрать ядро / выйти | ПКМ или F |
| Выбор инструмента | 1, 2 или колесо мыши |
| Прыжок / бег | Пробел / Shift |
| Пауза | Esc или P |

Клавиши физические: русская раскладка не меняет назначение.
После возврата в браузер или рекламы нужно нажать «Продолжить».

## Сборка без терминала на рабочем компьютере

После загрузки исходников в GitHub открой вкладку **Actions**, выбери
`Godot Web · Пепельные нити` и **Run workflow**. Сборка также запускается на push в `main`.

Workflow проверяет JavaScript, структуру проекта, загружает официальный Godot
и matching templates, проверяет SHA-512, импортирует проект, запускает
`tests/smoke.gd` и экспортирует HTML5. При обнаружении ошибок сборка останавливается.

После зелёной сборки скачай artifact `pepelnye-niti-yandex`. Из внешнего архива
artifact достань **внутренний** `pepelnye-niti-yandex.zip`: именно он предназначен
для тестового черновика Яндекс Игр. В его корне находятся `index.html`, WASM и PCK.
Бюджет распакованной сборки проекта — 100 MB. Workflow ничего не публикует
автоматически, не включает GitHub Pages и не изменяет видимость репозитория.
Расход GitHub Actions зависит от тарифа и установленных в аккаунте лимитов.

Для локальной сборки при наличии Godot и шаблонов:

```bash
node --test tests/bridge.test.cjs
python tools/validate_source.py
python tools/export_web.py --godot /absolute/path/to/godot
```

Скрипт требует пустую папку `build/web`, чтобы случайно не упаковать старые файлы.
Он не удаляет прежнюю сборку автоматически. Для проверки уже экспортированных
файлов без платформы можно запустить `python -m http.server 8000 --directory build/web`
и открыть `http://localhost:8000`. Ошибка загрузки `/sdk.js` на таком локальном
сервере ожидаема: игра переходит в локальный режим без рекламы.

## Яндекс Игры

HTML-оболочка подгружает `/sdk.js`. JS-мост ставит `LoadingAPI.ready()` в очередь,
пока SDK не инициализирован, и отправляет готовность один раз. `GameplayAPI`
отражает реальный запуск и остановку игры. Потеря фокуса и события SDK ставят
игру на паузу, выключают звук; возвращение не возобновляет её автоматически.

Полноэкранная реклама запрашивается только с экрана результата, при явном
нажатии «Ещё одна попытка / Попробовать снова». Нет внешних платежей,
обязательной авторизации, платных ассетов, облачных ключей и имитации просмотров.
Монетизацию ещё нужно включить в консоли. Сохранение локальное: cloud saves
в карточке включать не нужно. При запрете хранилища выводится предупреждение.

Перед публикацией обязательно пройти [чек-лист](docs/release-checklist.md).
Ни наличие SDK в исходниках, ни успешная сборка не гарантируют модерацию.
