# Статус проверок

Дата: 15 сентября 2026. Версия: 0.1.0.

## Среда

Godot и Godot CLI не установлены. Запрос скачивания движка из официального
GitHub release закончился тайм-аутом соединения через прокси. Другие маршруты
для обхода сетевых ограничений не использовались.

## Статические проверки

- `node --test tests/bridge.test.cjs`: **9/9 пройдено**. Это тесты JS-моста
  с моками SDK, а не настоящие показы рекламы.
- `node --check web/bridge.js` и `node --check web/boot.js`: пройдено.
- `python tools/validate_source.py`: пройдены ссылки на ресурсы, параметры Web
  export, синтаксис Python, разбор SVG и заголовки четырёх PCM WAV.
- YAML GitHub Actions разобран локальным YAML-парсером; есть push, pull_request
  и workflow_dispatch, права репозитория ограничены `contents: read`.
- Четыре оригинальных WAV сгенерированы и включены в проект.

Эти проверки **не подтверждают синтаксис GDScript, работоспособность игры,
визуальное качество или прохождение модерации**.

## Не выполнено

- Экспорт WASM/PCK и проверка фактического размера Web-сборки.
- Визуальная проверка, ручное прохождение, замеры FPS и памяти.
- Запуск в реальных браузерах и на телефоне.
- Проверка настоящего SDK и рекламы на Яндекс Играх.
