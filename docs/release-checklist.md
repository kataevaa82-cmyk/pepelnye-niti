# Проверка перед публикацией

Ни один пункт ниже не считается пройденным только потому, что написан код.

## Движок и игра

- [ ] Импорт Godot 4.4.1 без ошибок GDScript; `tests/smoke.gd` зелёный.
- [ ] Web export, загрузка WASM/PCK и старт в Chromium и Firefox.
- [ ] Визуальная проверка: свет, читаемость, захват мыши, проходы и камера.
- [ ] Удар пробивает отверстие, верхние блоки падают без опоры.
- [ ] Металл ломается двумя ударами или импульсом; пять зарядов не уходят в минус.
- [ ] Нельзя брать ядро сквозь стену; выход требует все три ядра.
- [ ] Первое ядро запускает тревогу; до него можно готовить маршрут без ограничения.
- [ ] Полный честный проход: три ядра, уклонение от Сборщика, возвращение.
- [ ] Проигрыш при нуле здоровья или времени, перезапуск после результата.
- [ ] Физика не работает под меню; звук остановлен на паузе и при потере фокуса.
- [ ] Сохранение и восстановление разрушений, ядер, позиции, времени и рекорда.
- [ ] Не возникает застревания при восстановлении сохранённой позиции.
- [ ] Замер FPS и памяти на типичном компьютере; отсутствие деградации после 10 попыток.

## Платформа

- [ ] Внутренний Web ZIP: `index.html` в корне, все зависимости включены.
- [ ] Нет ошибок SDK в черновике Яндекса; `/sdk.js` подгружается самой платформой.
- [ ] LoadingAPI и GameplayAPI проверены через debug-панель.
- [ ] Реальная реклама: открытие, закрытие, отсутствие рекламы, ошибка, потеря фокуса.
- [ ] Не начинается геймплей и не звучит аудио под рекламой.
- [ ] Реклама настроена в консоли; нет внешних платежей.
- [ ] Сохраняется гостевой прогресс; корректно сообщается об отключённом localStorage.
- [ ] Русская и английская раскладки дают одинаковые действия.
- [ ] Окно 800×600, 1280×720, 1920×1080, широкое окно и изменение размера.
- [ ] Нет контекстного меню, выделения, прокрутки страницы и случайного page refresh.
- [ ] До мобильных тестов указать только ПК. Для mobile отдельно проверить touch,
      ориентации, размеры кнопок, FPS, полноэкранный режим и доступность управления.
- [ ] Перед подачей повторно сверены актуальные требования платформы.
